CANONICAL QUESTION
Let pi = 3.d_1 d_2 d_3 ... be its unique nonterminating decimal expansion, with d_i in D = {0,...,9} for every integer i >= 1. For every integer n >= 1 define F_pi(n) = {(d_i,...,d_(i+n-1)) : i >= 1} and p_pi(n) = |F_pi(n)|. Do there exist a real eta > 0 and an integer N >= 1 such that, for every integer n >= N, p_pi(n) >= 10^(eta*n)? Equivalently, is the decimal factor entropy h_10(pi) = lim_(n->infinity) log_10(p_pi(n))/n strictly positive? The limit exists because p_pi(n+m) <= p_pi(n)*p_pi(m). Status: OPEN pending a source-pinned audit; the question is expected to be hard.

PROVENANCE
Formulated by this system on 2026-07-22 as a successor to pi-decimal-factor-complexity and from the entropy, collision, empirical-measure, and Fourier obstructions accumulated in the pi-digits, pi-positive-lower-block-density, pi-quantitative-block-hitting, and pi-lacunary-near-return-sparsity programs. Irrationality gives only the linear Morse-Hedlund baseline, and transcendence or a finite irrationality measure is not known to imply positive factor entropy. Named context to pin before use includes Morse-Hedlund, Fekete's subadditive lemma, and the Adamczewski-Bugeaud complexity literature. The feedback path to local:pi-digits is an entropy ladder: collision and Fourier certificates developed here are intended to raise lower bounds on h_10(pi); if a length-m word is absent then h_10(pi) <= log_10(10^m-1)/m, so a verified lower bound above this threshold certifies every length-m word, while h_10(pi) = 1 is equivalent to disjunctivity. Positive entropy alone does not imply occurrence of every word.

RECORDED AMBIGUITIES
A1 (CANONICAL): one fixed eta > 0 works for every sufficiently large n. Status: OPEN.
A2: limsup_n log_10(p_pi(n))/n > 0. This is equivalent to A1 after proving submultiplicativity and existence of the limit.
A3: one fixed exponential rate holds for infinitely many n. This is equivalent to A1 once the same limit theorem is established.
A4: p_pi(n) >= c^n for every n >= 1 for one c > 1. This is equivalent to A1 after reducing c and using the irrationality baseline for finitely many small n.
A5: h_10(pi) >= eta_0 for a prescribed eta_0 > 0. This is stronger than A1. Status: OPEN.
A6: h_10(pi) = 1. This is stronger than A1 and is equivalent to local:pi-digits after the forbidden-word entropy gap is proved. Status: OPEN.
A7: p_pi(n) = 10^n for every n. This is exactly local:pi-digits, not the canonical target. Status: OPEN.
A8: p_pi(n)/n tends to infinity. This is the existing pi-decimal-factor-complexity target and is strictly weaker than A1. Status: OPEN.
A9: p_pi(n) grows faster than every polynomial. This can still have zero entropy and is weaker than A1. Status: OPEN for pi.
A10: allow eta to depend on n without a uniform positive lower bound. This is vacuous and excluded.
A11: positive Shannon entropy of single-digit frequencies, or positive measure entropy of one empirical cluster measure. These are different measure-theoretic statements and are not the canonical factor-language entropy.
A12: positive Kolmogorov-complexity rate of prefixes. This is a different reading and is FALSE for the standard unconditional complexity because pi is computable.
A13: count only aligned or nonoverlapping blocks. This changes the language unless a separate transfer is proved and is excluded.
A14: count factors only in a prescribed finite prefix. This is a bounded sibling problem, not A1.
A15: positive topological entropy of the shift-orbit closure of the decimal digit stream. This is the intended equivalent dynamical formulation of A1.
A16: every word has positive lower frequency. This is the stronger existing pi-positive-lower-block-density target and implies full entropy.
A17: change base 10 to another base. This is a different problem; no cross-base transfer is assumed.
A18: include the integer digit 3. This finite shift does not change entropy but is excluded from the canonical convention. Noncontiguous subsequences and prefixes only are also excluded.
