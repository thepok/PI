                                                  Abstract. Let {an }n∈N , {bn }n∈N be two infinite subsets of positive integers and
                                                  ψ : N → R>0 be a positive function. We completely determine the Hausdorff
                                                  dimensions of the set of all points (x, y) ∈ [0, 1]2 which satisfy kan xkkbn yk < ψ(n)
                                                  infinitely often, and the set of all x ∈ [0, 1] satisfying kan xkkbn xk < ψ(n) infinitely
                                                  often. This is based on establishing general convergence results for Hausdorff
                                                  measures of these two sets. We also obtain some results on the set of all x ∈ [0, 1]
                                                  such that max{kan xk, kbn xk} < ψ(n) infinitely often.

   There also have been many works on multiplicative Diophantine approximation
