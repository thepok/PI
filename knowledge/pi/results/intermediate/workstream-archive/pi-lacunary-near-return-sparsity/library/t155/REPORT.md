**Fingerprint.** Mark each collision event by its pair of starting positions

### Quantitative applicability test F1-IID

Let `M` symbols be independent uniform elements of an alphabet of size
`q=10^m`. Index unordered pairs `alpha={i,j}` and let `I_alpha` indicate
equality. Give each event its pair-position mark. Then

```text
p_alpha=q^(-1),  P=binom(M,2),  lambda=P/q.
```

Take `A_alpha` to contain pairs sharing an endpoint with `alpha`; then
`|A_alpha|<=2M-3`. Outside `A_alpha`, independence makes Chen--Xia's
outside-neighborhood term `epsilon_1` zero. Distinct overlapping pair-equality
events have joint probability `q^(-2)`. Bounding every denominator
`V_alpha+1` below by one in Theorem 4.1 gives the explicit sufficient error

```text
d2 <= 2*P*(2M-3)*(5/lambda+3)/q^2
   = 2*(2M-3)*(5/q + 3P/q^2).                           (F1-error)
```

For the concrete sibling `m=8`, `q=10^8`, `M=1000`, this equals
`0.0002002985009 < 2.004e-4`. The ordered diagonal-inclusive collision
expectation is

```text
M + 2*lambda = M + M*(M-1)/q = 1000.00999.             (F1-mean)
```

Thus event-location Poisson approximation can be quantitatively strong while
the T7 scale still separately requires
`M+M*(M-1)/q<=M^2/(A*m)`. This test is an iid sibling experiment. Failure of
that mean inequality is failure of a sufficient calibration, not falsification
of Chen--Xia Theorem 4.1.
