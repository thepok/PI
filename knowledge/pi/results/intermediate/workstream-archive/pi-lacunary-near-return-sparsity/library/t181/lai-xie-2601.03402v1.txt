                                                      ABSOLUTELY NORMAL SETS OF UNIQUENESS

                                                                        CHUN-KIT LAI AND YU-HAO XIE


                                                 Abstract. We construct a class of homogeneous Cantor-Moran measures with all
                                                 contraction ratios being reciprocal of integers, and prove that they are pointwise
                                                 absolutely normal. Our approach relies on methods developed by Davenport, Erdős
arXiv:2601.03402v1 [math.CA] 6 Jan 2026




                                                 and LeVeque [12] and properties of order of integers in the multiplicative groups.
                                                 The construction of these measures differs from the class of pointwise absolutely
                                                 normal self-similar measures introduced by Hochman and Shmerkin [18], in which
                                                 dynamical approaches were used.
                                                    As an application, for all gauge functions φprq with r{φprq Ñ 0 as r Ñ 0, we
                                                 obtain a set of uniqueness K with Hφ pKq ą 0. Moreover, we show that there exists a
                                                 pointwise absolutely normal measure µ of dimension one fully supported on K. The
                                                 result demonstrates that having a lot of absolutely normal numbers in a Cantor set,
                                                 even with dimension one, cannot guarantee that it supports a measure with Fourier
                                                 decay. It also shows that the DEL criterion being satisfied for all integers does not
                                                 guarantee any Fourier decay nor the supporting set is a set of multiplicity.

                            7. Discussions and open problems
   The main result of this paper established a special class of Moran sets, that forms
a set of uniqueness as well as it supports pointwise absolutely normal measures. It
raises questions to decide if these concepts are true in more general class Moran sets
in (1.4) with mixed integer bases and integer digit sets.
   Concerning sets of uniqueness, we have never found any Moran sets in (1.4) that
can support a Rajchman measure. It is not hard to see that if #Dn “ 2 for all n ě 1,
the resulting Moran set is a set of uniqueness. We conjecture that all of them are
indeed sets of uniqueness.
  Conjecture: Suppose that the Moran set in (1.4) has Lebesgue measure zero.
Then it must be a set of uniqueness.
  There have also been some classical studies of determining whether certain Moran
Cantor sets is a set of uniqueness (see Meyer [24]). In the old terminologies, they
considered symmetric Cantor sets with splitting into two subintervals in each iteration
under contraction ratios defined by a sequence of dissection ratios pξn q8
                                                                         n“1 such that
0 ă ξřn ă 1{2. In [24, Chapter VIII], Meyer showed that symmetric Cantor sets
with 8      2
       n“1 ξi ă 8 are always sets of uniqueness. No satisfactory answers have been
42                              CHUN-KIT LAI AND YU-HAO XIE

provided since then. Our results shed some lights on this problem. Further discussion
of symmetric Cantor sets can be found in [21].
   Concerning supporting a pointwise absolutely normal measure, the following is an
interesting question:
  (Qu 1): Can we give a classification on the mixed integer bases tMn un , so that
there exists some tDn un , for which the Moran set (1.4) fully supports a pointwise
absolutely normal measure?
  Our main result demonstrated an explicit example in which tMn un is a sequence
of infinitely many prime numbers with polynomial growth. It is not hard to see
that if tMn un is periodic, it cannot be a pointwise absolutely normal measure. From
this evidence, it is possible that a characterization based on the number of primes
appeared in tMn un can exist.
  Finally, our paper demonstrated the existence of an absolutely normal set of unique-
ness with positive Hausdorff measure, for which the gauge function can be made arbi-
trarily close to r. However, we have not settled the largeness problem for every gauge
function.
  (Qu 2): For all gauge functions φ with r{φprq Ñ 0 as r Ñ 0, does there exist a
set of uniqueness K such that Hφ pK X Aq ą 0?
     In the dual direction, the question can also be asked for sets of multiplicity.
  (Qu 3): For all gauge functions φ with φprq Ñ 0 as r Ñ 0, does there exist an
absolutely normal set of multiplicity K such that Hφ pKq ă 8 and it supports a
pointwise absolutely normal measure?
   By considering diophantine approximation with arbitrarily fast rate of approxima-
tions, Fraser and Nyugen recently showed that there exist arbitrarily thin sets that
supports Rajchman measures ([17, Theorem 2.6]) and hence they are sets of multi-
plicity. However, we do not expect these measures can have a sufficiently fast decay
to verify the DEL criterion. Thus, we do not know if it supports pointwise absolutely
normal measures. (Qu 3) thus remains open.
