This directory is the complete default research packet. Read it in this order:

1. [`TARGET.md`](TARGET.md)
2. [`VERIFIED_CONSUMER_PATH.md`](VERIFIED_CONSUMER_PATH.md)
3. [`T189_FMR_R1_R2.md`](T189_FMR_R1_R2.md)
4. [`FIRST_OPEN_PI_LEMMA.md`](FIRST_OPEN_PI_LEMMA.md)
5. [`SEPARATORS.md`](SEPARATORS.md)
6. [`ATTEMPT_LEDGER.md`](ATTEMPT_LEDGER.md)

The evidence subdirectories contain only the reports directly supporting that
packet. Everything else is preserved under [`../archive/`](../archive/) and is
not part of normal navigation or Pro prompts.

Admission rule: an active file must serve the exact target, shortest verified
consumer, current open rung, one of at most ten relevant separators, or the
compressed ledger. Keep the total active knowledge surface between 20 and 40
files and remove superseded duplicates immediately.
