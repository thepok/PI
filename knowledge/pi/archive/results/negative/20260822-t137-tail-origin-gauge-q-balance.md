\[

Q_m=\frac{q_{J_m}}{48},\qquad

## Formal finite-data gauge

For a formal parameter `tau`, transform

\[
\Theta\mapsto\Theta+\tau,\qquad
U_m\mapsto U_m+\tau,\qquad
W_m\mapsto W_m+Q_m\tau. \tag{3}
\]

This fixes `x_m=Theta-U_m`. It therefore fixes every exact phase, nearest
carry, residue, BAD sign, half-open endpoint, and BAD margin. It also fixes

\[
U_m-U_{m+1}=48b_{m+1}
\]

and every affine identity generated by individually named local increments.

This is a formal gauge of the finite branch data, not a second canonical value
of pi. For `tau!=0`, it violates the full canonical normalization
`U_m=48(pi-A_m)` and the boundary condition `U_m->0`. It can therefore audit
only deductions from finite BAD/phase data and local difference identities
that do not use an absolute tail, tail positivity or decay, moment structure,
or the fixed-pi normalization.

## Exact Q-balance

Take nonnegative conic multipliers `alpha_(m,s)` of the lower BAD inequalities

\[
\sigma_{m,s}y_{m,s}\ge d_{m,s}
\]

and set

\[
c_m=\sum_{s=-1}^{0}\alpha_{m,s}\sigma_{m,s}p_{m,s}.
\]

After summing (1), the coefficient of `Theta` is

\[
\sum_{m,s}\alpha_{m,s}\sigma_{m,s}Q_{m,s}
=\sum_mQ_mc_m.
\]

Thus an affine/conic branch-only deduction can eliminate the absolute tail
origin and yield a pure `W` inequality only under the exact balance

\[
\boxed{\sum_mQ_mc_m=0}. \tag{4}
\]

Adding the local recurrences does not change this requirement, because

\[
\frac{W_{m+1}}{Q_{m+1}}-\frac{W_m}{Q_m}=-48b_{m+1}
\]

is itself gauge invariant.

## Signed-variation leakage

Let

\[
h_r=J_{r+1}-J_r\in\{1,2\},\qquad e_r=2h_r-3\in\{-1,+1\},
\]

and consider gauge-invariant nonnegative local weights `lambda_r` in

\[
S_\lambda=\sum_{r=a}^{b}\lambda_re_r(W_{r+1}-W_r).

Under (3),

\[
S_\lambda\mapsto S_\lambda+\tau\Gamma_\lambda,
\qquad
\boxed{\Gamma_\lambda=
\sum_{r=a}^{b}\lambda_re_r(Q_{r+1}-Q_r)}. \tag{5}

If `Gamma_lambda!=0`, the restricted finite branch data cannot give a
`tau`-uniform pure one-sided bound for `S_lambda`; an absolute-tail term must
remain. This is a statement about the restricted affine/conic proof class. It
does not preclude a canonical bound that uses `U_m->0`, absolute tail bounds,
moment positivity, or nonlinear constraints.
