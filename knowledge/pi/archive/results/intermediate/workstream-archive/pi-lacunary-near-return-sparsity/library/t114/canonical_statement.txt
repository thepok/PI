CANONICAL QUESTION
For real x write ||x||_(R/Z) = inf_{m in Z} |x-m|. For integers n,N >= 1 define Q_pi(n,N) = |{(i,j) in {0,...,N-1}^2 : ||(10^i-10^j)*pi||_(R/Z) < 10^(-n)}|; pairs are ordered and the diagonal is included. Is it true that for every integer A >= 1 there exists an integer n_0 >= 1 such that, for every integer n >= n_0, there exists an integer N >= 1 satisfying A*n*Q_pi(n,N) <= N^2? Status: OPEN pending a source-pinned audit of this exact fixed-pi statement. The question is expected to be hard.

RECORDED AMBIGUITIES
A1 (CANONICAL): every A works at every sufficiently large n, with N allowed to depend on A and n. Status: OPEN.
A2: the bound holds for infinitely many n only. This is weaker and gives at most subsequential complexity information. Status: OPEN.
A3: one fixed A works. This is weaker and cannot yield unbounded complexity ratio. Status: OPEN.
A4: one N works for all large n, or N is prescribed as a function of n. These are stronger readings. Status: OPEN.
A5: the bound holds for every N. FALSE as stated, since Q_pi(n,N) >= N from diagonal pairs and the inequality fails when N < A*n.
A6: omit diagonal pairs while leaving N unrestricted. This is vacuous at N=1 and is excluded.
A7: use unordered pairs. With diagonals retained this is equivalent to A1 after rescaling A, but it is not the canonical normalization.
A8: replace < by <= at 10^(-n). This is equivalent for pi: non-diagonal equality would make pi rational.
A9: use ordinary absolute distance rather than distance modulo one. This is a different problem and does not encode decimal-orbit proximity.
A10: count equal length-n decimal factors instead of all metric near returns. This is the weaker collision-energy hypothesis C1 from the parent program; T8 proves A1 implies it, not conversely. Status: OPEN for pi.
A11: require a random-model pair-correlation asymptotic. This is stronger than A1. Status: OPEN for pi.
A12: replace the eventual quantifier by liminf_n inf_N n*Q_pi(n,N)/N^2 = 0. This is only the infinitely-many-n reading A2. The corresponding full limit zero is equivalent to A1 up to strict-inequality adjustment.
A13: replace pi, base 10, consecutive powers, or the scale 10^(-n). These are sibling problems and require a proved transfer.
A14: verify bounded n,A,N, or prove an almost-everywhere, iid, or Champernowne analogue. Such results are sibling evidence only.
A15: prove the T10 weighted Fourier hypothesis. This is a sufficient strategy for A1, not an alternative definition.
A16: infer local:pi-digits from A1. No such implication is known; the verified direct consequence is superlinear factor complexity.
