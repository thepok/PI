endpoint as T136. It is rejected before candidate counting.

tuple)` keys inside the T153 source ledger. For the regression fixtures, it
reads the byte-pinned T104/T136/T138/T146 reports and vendored T138/T146 source
pins, verifies identifying anchors and every encoded supporting locator, and
compares explicit normalized `(source SHA, theorem identity, mechanism ID)`
records. This mechanically rejects T104/T138 C-UDEXP and each of the three
T136/T146 NEG-M/NEG-F/NEG-X repetitions rather than accepting fixture hashes or
prose markers as sufficient.
