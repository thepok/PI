## Exact polynomial

For every natural `H >= 2`, put

```text
c_H(h) = 1/H * [sin(pi*h/H)/pi + 2*(1-h/H)*cos(pi*h/H)],
M_H(x) = 2/H + 2*sum_(1 <= h < H) c_H(h)*cos(2*pi*h*x).
```

The file proves the zero mode `2/H`, the interior signed coefficients, even
extension to negative frequencies, and vanishing at every `|h| >= H`. It
also proves a single `u in (1/2,1)`, independent of `H`, with

```text
c_H(h) > 0  iff h/H < u,
c_H(h) = 0  iff h/H = u,
c_H(h) < 0  iff u < h/H
```

for every integer frequency `1 <= h < H`. The proof constructs the unique
root of `tan(t)-2t` between `pi/4` and `arctan(4)` and transfers its three sign
ranges to the coefficient shape.

## Majorization and endpoints

The strict indicator is

```text
I_H(x) = 1 if circleDistance(x) < 1/(2H), and 0 otherwise.
```

The file proves for every real `x`

```text
I_H(x) <= M_H(x).
```

No Vaaler inequality is assumed. Finite trigonometric sums first yield a
closed form for `M_H`. Its central lower bound reduces to the checked scalar
inequality

```text
1 <= sin(t)^2 *
  [1/t^2 + 1/(pi-t)^2 + 2/(pi*t*(pi-t))],  0 < t < pi.
```

That inequality is proved from elementary sine/cosine bounds and explicit
positive Bernstein-basis polynomial certificates. Outside the central
interval, the same closed form proves `M_H(x) >= 0`, including its removable
singular cases by finite endpoint identities and periodicity.

Both strict endpoints are exposed separately:

```text
I_H( 1/(2H)) = 0,   M_H( 1/(2H)) = 1,
I_H(-1/(2H)) = 0,   M_H(-1/(2H)) = 1.
```

Thus equality is not silently changed from `<` to `<=`.
