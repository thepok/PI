# Historical π knowledge archive

This subtree preserves superseded results, old workstreams, handoffs, states,
statements, and GPT Pro coordination material. Archive content is not false by
default; it is simply outside the current research frontier.

Do not load this tree during ordinary orientation or Pro prompting. Search it
only to answer a specific novelty, provenance, or duplication question. The
strict verifier still scans every tracked Lean file here.

Prefix migration:

```text
knowledge/pi/OVERVIEW.md  -> archive/navigation/OVERVIEW-legacy.md
knowledge/pi/results/     -> archive/results/
knowledge/pi/workstreams/ -> archive/workstreams/
knowledge/pi/handoffs/    -> archive/handoffs/
knowledge/pi/programs/    -> archive/programs/
knowledge/pi/state/       -> archive/state/
knowledge/pi/statements/  -> archive/statements/

```

Use `git log --follow -- <path>` and commit-pinned GitHub URLs for historical
provenance. Do not create thousands of compatibility stubs; that would restore
the navigation problem this archive solves.
