## Mission

for the actual constant π. The immediate constructive summit is signed horizon
transport:

```text

  -> fresh target-signed mass at horizon 10q
  -> same-digit positive surplus
  -> unbounded consistently reached path
  -> viable branching / word coverage
  -> V1.
```

At a positive natural-diagonal node define

```text
G_d=B(10q,A+dq,q)-B(q,A,q),
D_d=B(10q,A+dq,10q)-B(10q,A+dq,q)
   =q(Delta_0+Xi_d)-21/10.
```

The fixed T189 consumer requires

```text
exists d<10: D_d>0 and G_d+D_d>0.                 (FMR)
```

Work backward through the witness-preserving split

```text
R1: {d:D_d>0} is nonempty;
R2: one digit in that set has G_d+D_d>0.
```

The current first open π-specific rung is a quantitative lower bound for a
literal paired predecessor sector `P_r` that implies R1 on one unbounded,
consistently reached path, or a genuinely shorter aligned estimate that
directly implies FMR. Pair-sector amplitude alone does not align R2. Assuming
the reached path in the premise is circular. A single ray later needs word
coverage.

For every candidate ask where the actual-π target-signed information enters.
Do not accept symmetry, averaging, almost-everywhere results, denominator or
period information, congruences, unsigned energy, rational shadows, or finite
