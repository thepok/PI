# Workflows

Only current PI support remains here:

- `verification/`: strict all-tracked-Lean scanner and axiom audit;
- `experiments/`: focused reproducible checks used by current evidence;
- `experiments/data/`: versioned inputs required by those experiments;
- `state/`: ignored runtime state, never mathematical knowledge.

Project orchestration, prompts, modelbench, and runtime tooling live in the
[`AllMath` repository](https://github.com/thepok/MathMyth). This repository is
self-contained for PI experiments.
