# Web ChatGPT Pro

ChatGPT Pro is used only for hard creative mathematics at the current
[`FRONTIER.md`](../../FRONTIER.md). Up to three independent conversations may
run concurrently: a constructive signed-frontier slot, a proof/adversarial
slot, and a fundamentally different π-specific slot.

Never cancel an active run. Allow slow Pro turns to finish. Use at most five
follow-ups per conversation and only when a memo has genuine momentum or an
artifact must be recovered. Only one follow-up may be active in a given
conversation.

Raw run state, browser data, downloads, and transcripts live under the ignored
`workflows/state/`; they are not knowledge or proof authority. Integrate only
independently audited mathematics, distilled to the active result or to the
compressed attempt ledger.

Login, account-selection, browser-permission, rate-limit, or break conditions
require an immediate stop and notification to Marcel.
