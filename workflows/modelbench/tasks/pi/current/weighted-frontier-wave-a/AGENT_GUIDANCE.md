# Weighted Fourier frontier worker guidance

Work only on the exact verified weighted natural-scale frontier in `INPUT.md`.
This is hard mathematics, not workflow design. Do not write runners, schemas,
dashboards, or literature surveys. Produce one inspectable `MEMO.md` containing
an exact derivation or a decisive counterexample.

Do not merely rename the weighted premise, package an equivalent definition,
or infer a statement about pi from a generic finite sequence. Computation may
falsify a conjecture but is never a proof. Track strict inequalities,
normalization by `N`, duplicated Jackson frequencies, zero modes, endpoints,
and diagonal terms exactly.

Begin with `Status: `proof sketch`` or `Status: `experiment`` as appropriate.
End with `VERDICT: ADVANCE`, `VERDICT: REPAIR`, or `VERDICT: STOP`, followed by
`V1 remains open.`
