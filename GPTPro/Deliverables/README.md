# Deliverables

This directory contains concrete GPT Pro research outputs, one subdirectory per task ID.

A deliverable may be a checked proof, candidate Lean module, source-pinned audit, exact reduction, counterexample, executable experiment, dataset, or durable negative result. Each task directory requires a `README.md` with the claim label, result, evidence, verification, limitations, and intended canonical integration.

Accepted durable conclusions should be promoted or linked into `TheoryLib/`, `audit/`, or `knowledge/pi/`. This directory does not replace those authorities.
